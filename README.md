# tp-hw-2
# Система управления рецептами

Консольное приложение для создания блюд, добавления ингредиентов, масштабирования порций и генерации списка покупок.

## Установка

```bash
git clone https://github.com/CODY-79-afk/tp-hw-2.git
cd tp-hw-2
pip install -r requirements.txt
```

## Использование

Запуск тестов:
```bash
pytest test_recipes.py -v
```
